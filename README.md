# IronSilk Weekly

Public site for ironsilkweekly.com, served by GitHub Pages from `main` / root.

- `index.html`: the publication
- `sportshub.html`, `backdater-tool.html`: tools
- `picks.html` + `public/`: TheDesk Best 3 (published outputs only)
- `desk/`: TheDesk public app (read-only: published picks, results and the public slate; no engine code, keys or settings)
